# CHANGELOG — AVC-Anime

## 1.3.3-dev (Task 23 — парсер серий, не собран в EXE)

### Исправлено
- **Наруто/Шиппуден «57–58 серий»**: приложение считало максимумом сетки грязное
  поле сайта `episodes.aired` (Шиппуден: 58 при 500 сериях в матрице). Максимум
  теперь берётся из видео-матрицы (`latestEpisodeNumber`), а aired показывается
  как справка «Вышло серий: X из Y» с честным предупреждением.
- **Ван-Пис «1180 vs 1157»**: сетка серий больше не смешивает озвучки —
  показывает серии выбранной озвучки (Субтитры = 1157), как плеер сайта;
  счётчик озвучек = уникальные метки («(1157 эп.)»).
- **Порча номеров**: «1168.5», «119+120», «119-120» больше не схлопываются
  parseInt'ом в 1168/119 — канонические кнопки с метками сайта.
- Голос «серия N» теперь работает для N > 999 (Ван-Пис 1157/1180).
- «Следующая серия» не ломается на двухсерийниках и спешлах (порядок по меткам).
- Демо-фолбэк и живой сайт проходят один и тот же пайплайн парсера.

### Добавлено
- «Порядок просмотра» (Порядок просмотра/franchise): structured
  `viewing_order` из API сайта → секция на странице аниме с типом, годом и
  отношением («после 101 серии» — текст сайта сохранён как есть); клик открывает
  тайтл в новой вкладке.
- Модель данных: `CanonicalEpisode` (метка + варианты озвучек/плееров),
  `DubCoverage`, `EpisodeStatistics` (declared/released/available/latest/next),
  `ValidationIssue`, `WatchOrderEntry` + placement.
- Валидатор: `SUSPICIOUS_AIRED_BELOW_MAX`, `EPISODE_COUNT_MISMATCH`,
  `NON_INTEGER_EPISODES`, `RANGE_EPISODES`, `UNPARSEABLE_LABELS`,
  `DUB_COVERAGE_GAP`, `DECLARED_COUNT_MISSING`, `NO_VIDEOS`.
- Диагностика: `GET /api/site/debug/{animeId}` (RAW→parsed→source→validation),
  секция «Парсер серий» в отладочной панели + экспорт JSON (без cookie/токенов).
- Кэш: версия парсера в ключах адаптера; клиентский кэш деталей с TTL 5 мин и
  guard'ом версии (устаревшие данные не показываются).

### Репозиторий
- Подготовлен GitHub-бэкап: `.gitignore` (БД с cookie, EXE >100МБ, модели,
  песочница), `.env.example`, исходники Electron-оболочки перенесены в
  `electron-app/`, добавлены PROJECT_STATE/ARCHITECTURE/RECOVERY/AI_HANDOFF.
