# 🎤 AVC-Anime — Anime Voice Controller

Голосовое управление аниме-сайтом **YummyAnime** с дивана: встроенный браузер вкладок,
плеер, библиотека аккаунта, расписание онгоингов, франшизы, персональные рекомендации —
и всё это голосом, без мыши и клавиатуры.

**Платформа:** Windows portable EXE (Electron + встроенный Next.js 16 UI + локальный
STT-слой faster-whisper). Веб-режим (`bun run dev`) используется для разработки и отладки.

📦 **Скачать последнюю версию:** https://github.com/HellShaftSam/AVC-AnimeVoiceCommand/releases/latest

---

## Архитектура

```
🎤 Голос (микрофон: PTT или always-listening)
   │
   ▼
STT — faster-whisper (ЛОКАЛЬНО, офлайн, русская речь; бандл Python-рантайма)
   │   гейты качества: no_speech_prob / avg_logprob → confidence
   ▼
Command Parser (ЛОКАЛЬНЫЙ, детерминированный: src/lib/voice/parser.ts; без AI API)
   │
   ▼
Command Executor (src/lib/avc/executor.ts — очередь, контекст, подтверждения)
   │
   ┌──────┴────────────────────┐
   ▼                           ▼
Browser (вкладки/навигация)   Player Control (серии, озвучки, громкость, пропуска)
   │                           │
   └──────────┬────────────────┘
              ▼
     YummyAnime Adapter (src/lib/sites/yummy/adapter.ts — JSON API + HTML-секции)
              │
              ▼
     Аккаунт YummyAnime (РЕАЛЬНАЯ сессия сайта: списки/оценки/избранное)
              │
              ▼
     Рекомендации (src/lib/recs — прозрачный гибридный алгоритм)
```

**Ключевой принцип:** ни одной координаты мыши. Всё на ссылках, полях, JSON API и
структуре страниц. Добавить второй аниме-сайт = новый класс с интерфейсом
`IAnimeSiteAdapter` — остальное приложение не меняется.

## Возможности

### 🗣 Голосовое управление
- **Два режима:** рация (удержание 🎤 или `Ctrl + Space`) и always-listening
  (автоостановка по тишине, VAD-гейт, настраиваемая чувствительность).
- **Офлайн-распознавание:** faster-whisper внутри приложения — интернет нужен только сайту.
  Фантомные команды из музыки/шума отсекаются гейтом уверенности Whisper и ползунком
  порога в настройках.
- **Естественные фразы:** «найди берсерк», «включи пятую серию», «громкость 50»,
  «перемотай на 2 минуты назад», «следующая озвучка», «открой наруто и включи третью серию».
- **Дедупликация и защита:** повторная фраза в течение 2.5 с исполняется один раз,
  эхо из колонок глушится 2 с, варианты поиска истекают через 30 с.
- **История команд** (только текст, без аудио) с повтором в один клик.

### 🧭 Навигация по сайту (вкладки → стрелки, v1.0.35)
- **ЕДИНАЯ ИСТОРИЯ НАВИГАЦИИ вместо вкладок:** переход в Каталог/поиск/аниме НЕ создаёт
  вкладок — места листаются стрелками «назад/вперёд» в панели навигации (как в браузере,
  горячие клавиши `Alt+←` / `Alt+→`). Голос: «назад», «вперёд».
- **Живой поиск в той же строке** (`Ctrl+F`): печатаете «Н» — все тайтлы на Н, «На» —
  все на «На», «Наруто» — все совпадения по приоритету букв (префикс → начало слова →
  вхождение). Для запросов из 1–2 букв (сайт ищет от 3) — локальный индекс популярных
  тайтлов.
- Секции: Главная · Каталог · ТОП-100 · Онгоинги · Анонсы · Расписание · Случайное ·
  Рекомендации · Компаньон. Сессия сохраняется и восстанавливается (старые сессии с
  вкладками мигрируют автоматически).
- **Липкая пагинация:** номер страницы прилипает к верху при прокрутке — переключить
  страницу можно в ЛЮБОЙ момент, не листая сетку до конца. Полная нумерация дублируется
  снизу.

### 🎛 Фильтры каталога и случайное (v1.0.35)
- **Каталог — панель фильтров с мультивыбором:** жанры (пересечение выбранных),
  годы (чипы + диапазон «от/до»), статус (онгоинг/анонс/вышел). Метаданные — из деталей
  тайтла (честно: сайт своих фильтров не имеет), кэш 5 минут.
- **Случайное по жанрам:** вкладка «Случайное» — чипы жанров + кнопка «Крутить»
  («Из всех» — прежнее поведение). Результат с кнопками «Открыть» / «Ещё раз».

### 📺 Франшизы и порядок просмотра
- На странице аниме — лента **«Франшиза и порядок просмотра»** (сайт, `viewing_order`):
  1 сезон → 2 сезон → фильмы → OVA/ONA, с подписями связей («продолжение», «после 141
  серии», «адаптация манги»).
- Текущий тайтл помечен «сейчас», клик открывает связанную часть в той же вкладке
  (назад — голосом или кнопкой).

### 📅 Расписание онгоингов и календарь релизов
- Раздел «Расписание» — **плитки строго по дням недели** (Пн–Вс), текущий день выбран
  автоматически.
- На каждой плитке — время выхода следующей серии и живой обратный отсчёт
  («через 2 ч 23 мин», «серия вышла»). **Время — по Астане (UTC+5)** независимо от
  настроек машины (сайт отдаёт абсолютные штампы — приложение переводит их в
  казахстанский пояс).
- **Анонсы:** на каждой плитке — дата премьеры/следующей серии и год; под сеткой —
  **календарь релизов** с листанием месяцами: известные даты анонсов (золотые точки)
  и еженедельные слоты онгоингов по расписанию (зелёные), клик по дню — список
  релизов с временем.
- **Онгоинги:** на плитках — номер следующей серии («серия 1181») и обратный отсчёт
  прямо в сетке.

### 👤 Аккаунт YummyAnime (thin client)
- Вход один раз — на реальном сайте (постоянная сессия). Пароли и cookie никогда
  не покидают профиль приложения.
- **Библиотека с сайта:** Смотрю / В Планах / Просмотрено / Брошено / Отложено / Любимые.
- Голосовые действия с reload-верификацией по серверному HTML: «добавь в смотрю»,
  «добавь в избранное», «оцени на 8», «убери оценку», «убери из списка».
- «Что я смотрю?», «продолжить просмотр» — локальный трекинг серий и позиции.
- Пользовательские алиасы: «добавь „ани либрия" как команду для AniLibria».

### ⭐ Персональные рекомендации (новое в v1.0.31)
Вкладка **«Рекомендации»** (кнопка на панели или «открой рекомендации» голосом):

- **Честная персонализация по вашему аккаунту:** профиль строится из реальных оценок
  (1–10), статусов списков, избранного и локального трекинга просмотра. Ничего не
  выдумывается; нет аккаунта — вкладка честно просит войти.
- **Объяснимый гибридный алгоритм** (без LLM и ML-рантайма), три принципа:
  1. **Фильтрация ДО ранжирования** — брошенное и низкооценённое не спасёт никакая
     похожесть; уже известные тайтлы исключаются; жанр целиком никогда не отвергается
     из-за одного брошенного тайтла.
  2. **Профиль обновляется от реальных действий** — поставили оценку/изменили статус/
     добавили в избранное → подборка пересчитывается после подтверждения сайтом,
     без ручного сброса и без постоянного поллинга.
  3. **Прозрачные веса** — итог = `100 × (0.42·похожесть + 0.28·аффинитет вкуса +
     0.20·франшиза + 0.10·качество)`, компоненты показываются раздельно.
- **Кандидаты из трёх источников:** франшизы ваших позитивных тайтлов (сиквелы/фильмы),
  каталог сайта (ТОП-100, онгоинги, каталог) и опционально AniList (выключено по
  умолчанию; сопоставление строго по MAL ID + точное название, всё проверяется на
  доступность на YummyAnime).
- **Каждая карточка — с причиной:** «Связано с „Наруто" (2 сезон)», «Похоже на „Клинок" —
  совпадают жанры: экшен, фэнтези», «Высокий рейтинг сайта: 8.4». Счётчик на карточке —
  внутренняя оценка соответствия, не вероятность.
- **Обратная связь в один клик:** «Не интересно» / «Уже видел» — скрывает тайтл до
  пересчёта входов; кнопка возврата отменяет отметку (одиночный клик не портит профиль).
- **Настройки вкладки:** порог оценки (1–10, по умолчанию 5 — ниже порога тайтлы
  исключаются), скрывать известные, разнообразие выдачи (MMR против «двадцати одинаковых
  шоу»), кандидаты AniList.
- **Холодный старт:** мало данных → честная общая подборка с явной меткой
  «не персональная» и подсказкой, что оценить.
- **Приватность:** снапшот подборки хранится только локально и только под вашим
  userId; выход из аккаунта инвалидирует все сохранённые подборки. Cookie/пароли в
  рекомендательных данных не хранятся никогда.

### 🌌 Anime Companion (новое в v1.0.33)
Вкладка **«Компаньон»** (кнопка рядом с «Рекомендациями» или голосом) — личный спутник
просмотра. Стиль — Celestial Dark Fantasy: звёздное небо, золотые узлы и линии.
Шесть разделов в одной вкладке (без плоджения вкладок):

- **Обзор** — «Продолжить просмотр» (последний тайтл и серия), счётчики
  (Смотрю/Избранное/Просмотрено/Незаконченные/Заметки/Моменты), последние записи хроник.
- **Компас настроений** — 13 осей («Мрачность», «Напряжение», «Уютная атмосфера»,
  «Политические интриги»…): выбор оси → подборка из соответствующей категории каталога
  сайта, плюс клиентские фильтры (тип TV/Фильм/OVA, минимальный рейтинг). Голосом:
  «найди что-нибудь мрачное с сильным героем».
- **Хроники зрителя** — личный дневник: заметки, цитаты, впечатления и **закладки
  моментов** (позиция воспроизведения). Всё хранится локально в SQLite приложения,
  поиск по тексту/тегам, редактирование и удаление.
- **Карта вкусов** — созвездие из ваших жанров и студий: строится ТОЛЬКО из реальных
  оценок (≥7), избранного и списков; каждая точка показывает, какие тайтлы к ней привели.
- **Квесты и достижения** — необязательные цели из реальных событий («Хроникёр —
  5 записей», «Завершитель — начатый тайтл доведён до конца», «Пятьдесят серий»…)
  + собственные цели пользователя. Без стриков, штрафов и уведомлений.
- **Персонажи** — состав тайтла через AniList (по MAL ID): только имена, роль и сэйю —
  **описания скрыты принципиально** (защита от спойлеров); тайтл выбирается из вашей
  истории просмотра.

Голосовые команды Companion: «сохрани этот момент» (закладка позиции во время
просмотра), «напомни, что происходило» (честное напоминание по ВАШИМ заметкам —
содержание серий приложению не известно и не выдумывается), «покажи незаконченные
аниме», «покажи порядок просмотра», «сколько серий осталось», «продолжи то, что
смотрел» (включая трекинг БД — переживает очистку браузера), «открой хроники/заметки/цитаты»,
«карта вкусов», «мои квесты», «открой компас», «открой персонажей».

### ▶ Плеер и пропуска
- Серии × озвучки с фактической матрицей доступности; озвучка сохраняется между сериями.
- **Пропуск опенинга/эндинга:** тайминги с сайта + Aniskip (по MAL ID) + ручные слайдеры;
  «пропусти опенинг», «запомни начало опенинга» (свои таймкоды в SQLite).
- Мини-плеер, полный экран, громкость/перемотка голосом.

### 🔄 Обновление приложения (внутри EXE)
- **Автопроверка при старте:** вышел новый релиз → янтарный бейдж на кнопке ⟳ + тост
  с кнопкой «Обновить».
- **Скачивается только portable EXE** — никаких отдельных файлов контрольных сумм:
  целостность сверяется по полю `digest` (SHA-256) из GitHub API, которое GitHub считает
  сам при загрузке релиза. Если digest недоступен — проверяются размер и PE-заголовок.
- Двухфазная установка: приложение завершается штатно → скрипт подменяет EXE → стартует
  новая версия → честное подтверждение версии в диалоге.
- **v1.0.35 — исправлено «обновление проходит, но ничего не происходит»:** в portable-
  сборке `app.getPath('exe')` указывал на ВРЕМЕННУЮ распакованную копию, а не на файл,
  который запустил пользователь. Подменяется реальный EXE (PORTABLE_EXECUTABLE_FILE);
  после подтверждения обновления старый подменённый EXE удаляется.
- Не совпала контрольная сумма — файл удаляется, установленная версия не трогается.
- Кнопка обновления в веб-режиме скачивает EXE напрямую с GitHub Releases.

### 🧹 Жизненный цикл (v1.0.35)
- **Закрытие приложения:** при выходе синхронно снимается дерево процессов
  (`taskkill /T /F`) — Next-сервер и AI-воркер больше не остаются висеть в Диспетчере
  задач; при старте добиваются сироты-процессы прошлых жёстких сессий.
- **Чистка temp:** при каждом старте удаляются устаревшие (старше суток) временные
  каталоги приложения — распакованные копии portable и остатки скачанных обновлений,
  которые накапливались на диске C.

## Реальные данные YummyAnime

| Ресурс | Эндпоинт |
|---|---|
| Поиск | `GET /api/search?q=` |
| Детали (жанры, студии, MAL ID, франшиза) | `GET /api/anime/{id}` и `GET /api/anime/{alias}` |
| Матрица серий × озвучек + skip-тайминги + iframe | `GET /api/anime/{id}/videos` |
| Каталог / онгоинги / анонсы / ТОП-100 (+ страницы) | HTML `/catalog`, `/catalog/ongoing`, `/catalog/announcement`, `/catalog/top` |
| Расписание по дням (unix-время серий) | HTML `/catalog/schedule` |
| Случайное аниме | `/catalog/random` (302-редирект) |
| Профиль и списки аккаунта | `GET /api/profile`, `GET /api/users/{id}/lists/{0..5}` |
| Действия аккаунта | `PUT/DELETE /api/anime/{id}/list`, `/list/fav`, `/rate` |

Все селекторы — в одном объекте `SELECTORS` адаптера. Кэш в памяти (TTL 5 мин).
Сайт недоступен → демо-датасет с честным бейджем «Демо-данные», приложение работает.

## Сборка и запуск

### Из исходников (разработка)
```bash
bun install
bun run db:push     # Prisma + SQLite (настройки, история, трекинг, сессия)
bun run dev         # http://localhost:3000
bun run lint        # ESLint
bun test tests/recommendations.test.ts   # тесты движка рекомендаций
```

### Windows EXE
Собирается автоматически: push в `main` → GitHub Actions
(`.github/workflows/build-exe.yml`) → portable EXE публикуется в Releases
(`AVC-Anime-Portable-1.0.<run_number>.exe`, только EXE, без сопутствующих файлов).
Внутри бандла: Next.js standalone-сервер, Electron-оболочка, локальный Node-рантайм
для AI-воркера, Python-рантайм faster-whisper, страж раскладки AI-слоя, STT-selftest
на реальном Windows до публикации.

### Настройки приложения
Общие (сайт, режим микрофона, Couch Mode) · Голос (порог уверенности, усиление
микрофона, чувствительность VAD, кап длины фразы, движок STT) · Плеер (шаги перемотки/
громкости, автопереход к следующей серии) · Пропуска (источники, режим, пороги,
свои таймкоды) · Рекомендации (порог оценки, известные, разнообразие, AniList) ·
Локальный AI-слой (профиль производительности). Всё в SQLite, применяется мгновенно.

## Известные ограничения (честно)

1. **STT** — офлайн faster-whisper (бандл): первая загрузка моделей требует место на
   диске; качество зависит от микрофона. Браузерный/серверный движки остаются
   переключаемыми в настройках.
2. **Плеер** — видео воспроизводится через iframe официального плеера сайта; прямое
   управление `<video>` внутри кросс-доменного iframe ограничено политикой браузера —
   в EXE есть Electron-мост, в веб-режиме часть команд работает через контекст приложения.
3. **Прогресс серий на сайте** наружу не отдаётся — приложение ведёт собственный честный
   трекинг (SQLite, изоляция по аккаунту).
4. **Рекомендации** — прозрачный эвристический рекомендатор: точность на исторических
   данных не измерялась (истории взаимодействий пока нет); измерения и усложнение
   модели — по мере накопления фидбека. AniList-кандидаты экспериментальны и выключены
   по умолчанию.
5. **Парсер локальный и детерминированный** — фразы вне словаря команд честно дают
   «Не распознано» (LLM-fallback удалён по решению владельца).
6. Живой микрофон/CUDA проверяются на машине владельца; песочница их не имеет.

## Диагностика и отладка

- 🐛 Отладочная панель → «Диагностика YummyAnime»: доступность, поиск, секции,
  расписание, случайное, матрица серий/озвучек — каждая проверка ✓/✗.
- Пайплайн каждой команды: RAW → NORMALIZED → COMMAND → PARAMS → CONFIDENCE → RESULT.
- Самопроверка аккаунта YummyAnime (состояния сессии, персистентность) — без секретов.
- `electron-app/tools/update-selftest.cjs` — 11 проверок цепочки обновления против
  живого GitHub (версии, digest-целостность, доступность).
